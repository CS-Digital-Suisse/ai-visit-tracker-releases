# AI Visit Tracker - Releases

Ce depot public contient les artefacts de release du plugin WordPress
**AI Visit Tracker** (code source sur le depot prive).

## Contenu

- `latest.json` : manifest de mise a jour (version, URL du zip, metadonnees).
- `ai-visit-tracker-X.Y.Z.zip` : zip versionne installable dans WordPress
  (Extensions > Televerser un plugin).

## Mises a jour automatiques

Le plugin inclut un updater natif WordPress qui lit `latest.json` et propose
la mise a jour dans l'interface d'administration. Les mises a jour
automatiques sont activees par defaut.
